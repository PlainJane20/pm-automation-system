# IT Project Intake Form

## Form Title
**IT Project Intake Request**

## Form Description
Submit your IT project, enhancement, or feature request here. The IT Leadership team will review all submissions and respond within 5 business days.

**All fields marked with * are required.**

## Tips for Using This Form

### For Requestors:
- Be as specific as possible - detailed requests get faster approvals
- If you're unsure about budget or technical details, that's okay - just note "TBD" or "Need IT estimate"
- Attach any supporting documents that help explain your request
- The more business value you can demonstrate, the higher priority your request

### For IT Leadership:
- Review submissions weekly in team meeting
- Use the assessment columns to score and discuss
- Approve/defer/reject with clear reasoning
- Create JIRA Epics for approved projects immediately
- Communicate decisions back to requestors promptly
